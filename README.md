# 🎮 Tic-Tac-Toe Game (Python Tkinter)

A simple, interactive **2-player Tic-Tac-Toe game** built using **Python’s Tkinter GUI library**.

This project demonstrates how to build a GUI application in Python with event-driven programming, turn-based game logic, and win/lose/tie detection—all in a clean and user-friendly interface.

---

## 📚 About This Project

Key aspects of the project:

- ✅ GUI-based application using Python’s built-in Tkinter library
- ✅ Interactive 2-player game (X vs O)
- ✅ Highlights winning cells in green
- ✅ Highlights tie (draw) board in yellow
- ✅ Highlights losing cells in red
- ✅ Reset button to restart the game
- ✅ Randomly selects which player starts

This project is ideal for beginners learning **GUI programming, game logic, and Python event handling**.

---

## 🚀 Features

- 🆚 2-player mode (X vs O)
- 🎲 Random start player selection
- 🏆 Automatic win detection with green highlight for winning line
- 🤝 Tie detection with yellow highlight
- 🔄 Reset/Restart button
- 🖥️ No external dependencies—runs with standard Python + Tkinter
